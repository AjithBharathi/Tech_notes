A Tiny "Pro" Tip
While your code is perfect for standard arrays, in competitive programming or with massive arrays, the way you calculate middle can technically cause an Integer Overflow if start + end exceeds the maximum number limit (
 in JavaScript).
The "Professional" way to write that line is:
javascript
let middle = Math.floor(start + (end - start) / 2);
